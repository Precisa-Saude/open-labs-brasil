# Suporte

## Como obter ajuda

| Assunto                                                     | Canal                                                                                                                                   |
| ----------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Dúvida sobre o texto, ambiguidade, resultado da suíte       | [Issue](https://github.com/Precisa-Saude/open-labs-brasil/issues)                                                                       |
| Defeito no servidor de exemplo, na suíte ou nas ferramentas | [Issue](https://github.com/Precisa-Saude/open-labs-brasil/issues), com o modelo de defeito                                              |
| Proposta de mudança no protocolo                            | [Issue](https://github.com/Precisa-Saude/open-labs-brasil/issues), com o modelo de proposta ([GOVERNANCE.md](GOVERNANCE.md), seção 4.2) |
| Laboratório que quer experimentar em homologação            | [docs/roteiro-do-piloto.md](docs/roteiro-do-piloto.md)                                                                                  |
| Falha de segurança                                          | Em privado, pelos canais do [SECURITY.md](SECURITY.md)                                                                                  |

## Antes de abrir uma issue

1. Pesquise issues existentes para evitar duplicatas
2. Diga a versão da especificação (por exemplo, 0.2.2) e, se for o caso, o capítulo e a seção
3. Para defeito nas ferramentas, inclua o comando exato, a saída e as versões do Node e do pnpm
4. Não inclua dado de paciente real
